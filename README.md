# ArcadeClip

<img src="src/assets/icon.png" alt="" width="104" align="left" style="padding-right: 01em;">

maimai 플레이를 길게 녹화한 영상에서 곡을 찾아, 곡별 MP4 파일로 분할 저장하는 Windows 앱입니다.

[소개 페이지](https://151net.github.io/ArcadeClip/) · [사용 설명서 · 한국어 / English](https://151net.github.io/ArcadeClip/manual.html)

## 시작하기

처음 한 번만 하는 준비입니다.

1. 배포 폴더의 `ArcadeClip.exe`를 실행하세요. 폴더 안의 다른 파일도 함께 두세요.
2. **폴더 선택**으로 데이터 폴더를 지정하세요. 곡 자켓 약 100 MB를 이 폴더에 받습니다.
3. **시작하기 →**를 누르고 다운로드가 끝날 때까지 기다리세요. 약 10분이 걸릴 수 있습니다.

다음 실행부터는 같은 폴더의 파일을 다시 씁니다. 앱에서 **도움말** 또는 **F1**을 누르면 설명서가 열립니다.

## 클립 저장하기

순서대로 진행합니다.

1. **영상 열기** — **파일 추가** 또는 **폴더 추가**로 영상을 여세요. 창으로 끌어와도 됩니다.
2. **시간 범위 지정** — 곡을 찾을 **시작**과 **끝**을 정하세요. 영상 전체에서 찾으려면 **전체 구간**을 누르세요.
3. **곡과 글자 위치 지정** — **자켓**·**1P 이름**·**1P 달성률** 영역을 영상 위에 사각형으로 그리세요. 같은 촬영 구도로 저장해 둔 프로필이 있으면 **프로필 선택**에서 고르면 됩니다. **이 구간에서 곡 찾기 →**를 누르면 곡을 찾습니다. 긴 영상은 시간이 오래 걸릴 수 있습니다. 하단 진행 상태를 확인하세요.
4. **클립 확인** — 찾은 클립을 재생해 확인하고, 저장할 클립에 체크하세요.
5. **파일 저장** — **폴더 선택**으로 저장 위치를 고르고, 파일명을 확인한 뒤 저장을 시작하세요.

저장이 끝나면 **선택한 폴더 열기**로 결과를 확인하세요.

## 필요할 때만 하는 편집

아래 A·B·C는 선택 사항입니다. 하지 않아도 클립을 저장할 수 있습니다.

- **A. 곡명·이름·달성률 고치기** — 이 값은 파일명을 만들 때만 씁니다. 영상에 글자로 들어가지 않습니다. 파일명이 괜찮다면 고치지 않아도 됩니다. 고친 뒤에는 **수정 적용**을 누르세요.
- **B. 클립의 시작·끝 조정** — 곡 앞뒤를 더 담으려면 파란 구간의 양끝을 드래그하세요. **클립 시작·끝 일괄 조정**에서 모든 클립에 한 번에 적용할 수도 있습니다.
- **C. 저장 방식 바꾸기** — 기본은 **원본 빠른 복사**입니다. 빠르지만 시작·끝이 조금 달라질 수 있습니다. 경계를 정확히 맞추거나 화질·용량을 조절하려면 **저장 설정**에서 **정확한 구간 자르기**를 고르세요. 저장에 시간이 더 걸립니다.

## 자주 필요한 작업

| 하고 싶은 일 | 여는 곳 |
|---|---|
| 새로 나온 곡이 인식되지 않을 때 | **Settings → 곡 데이터 업데이트** |
| 영어로 사용하기 | **Settings → Language → English**, 앱 다시 열기 |
| 다음에 이어서 편집하기 | **작업 저장** → 다음 실행에서 **작업 열기** |
| 곡을 자주 놓치거나 잘못 찾을 때 | **Settings → 자켓 · 글자 인식 설정…** |
| YouTube 영상의 일부만 쓰기 | 영상 열기 화면의 **YouTube 링크** |
| 저장이 실패했을 때 | **Settings → 진단 로그** |
| 새 버전이 나왔는지 보기 | **Settings → 새 버전 확인** |
| 문제를 알리기 | **Settings → 문제 신고** |

## 실행 환경

Windows 10·11 x64에서 사용하세요. 다른 운영체제용 배포본은 아직 제공하지 않습니다.

## 소스에서 실행하기

Python 3.11 이상과 [uv](https://docs.astral.sh/uv/)가 필요합니다. FFmpeg는 `tools/` 폴더 또는 PATH에 두세요.

```sh
uv sync --locked
uv run start.py
```

준비물과 검사 실행은 [개발 환경 준비](docs/develop/SETUP.md)에 있습니다.
