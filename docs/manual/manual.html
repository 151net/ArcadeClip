0. 어떻게 진행되나요?

영상에서 곡을 찾고, 필요한 구간을 클립으로 저장합니다. 원본 영상은 그대로 유지됩니다.

  1. 영상 열기
  2. 시간 범위 지정
  3. 곡·글자 위치 지정 → 곡 찾기
  4. 클립 확인·저장 대상 확정
  5. 영상 파일 저장

처음 실행한다면 다음 ‘환영합니다’부터 시작하세요. 이미 설정했다면 ‘영상 열기’로 이동하세요.

어떤 영상에서 곡을 찾을 수 있나요?

곡 인식은 화면의 자켓을 공식 자켓과 비교하는 방식입니다. 인식 영역 안에 자켓이 정사각형 그대로, 잘리지 않고 들어와야 인식됩니다.

환영합니다 · 처음 한 번

데이터 폴더를 정하면 곡 인식에 필요한 파일을 받습니다.

폴더 선택으로 데이터 폴더를 지정하세요. 최초 1회 곡 자켓 약 100 MB를 다운로드합니다.

시작하기 →를 누르세요. 다운로드에 약 10분이 걸릴 수 있습니다. 완료될 때까지 기다리세요.

3. 곡과 글자 위치 지정하기

같은 촬영 구도라면 저장한 프로필을 사용하세요.

프로필 고르기 또는 새 프로필 만들기

프로필 선택에서 프로필을 고르세요. 받은 JSON·ZIP 파일은 오른쪽 가져오기 아이콘으로 여세요.

새 프로필 만들기

영역 선택에서 자켓(곡 이미지)을 고르세요.

자켓 전체가 들어오도록 드래그하세요. 1P 이름과 1P 달성률도 각각 글자를 감싸도록 지정하세요. 오른쪽 예시와 현재 지정 영역을 비교하면 범위를 확인할 수 있습니다.

프로필 저장·공유

필수 영역은 자켓·1P 이름·1P 달성률입니다. 2P 영역은 필요할 때 추가하세요. 프로필 저장으로 같은 촬영 구도에 다시 사용하고, 프로필 내보내기로 JSON·ZIP 파일을 공유하세요.

인식 확인과 곡 찾기

현재 화면 인식 확인을 누르세요. 인식한 곡명과 이름을 확인하세요.

이 구간에서 곡 찾기 →를 누르세요. 긴 영상은 곡 찾기에 시간이 오래 걸릴 수 있습니다. 하단 진행 상태를 확인하세요.

4. 클립 확인하기

클립을 선택하면 편집할 수 있습니다. 체크박스는 저장할 클립을 표시합니다.

저장할 클립 선택하기

목록에서 클립을 선택하면 편집할 수 있습니다. 저장할 클립은 체크박스로 표시하세요.

이름을 검색해 목록을 좁히세요. 보이는 클립 체크는 현재 보이는 항목에 체크합니다. 필터로 숨긴 클립의 체크는 유지되므로, 저장 전에 하단의 저장 대상 수를 확인하세요.

체크한 클립 …개 저장 설정 → 또는 보이는 클립 …개 저장 설정 →로 저장 대상을 확정하세요. 파일은 다음 화면에서 저장합니다.

클립 수정하기 · 선택 사항

파일명이나 챕터 제목을 바꾸려면 곡명·이름·달성률을 수정하고 수정 적용을 누르세요. 확인한 클립은 검수 완료로 표시에 체크할 수 있습니다.

필요할 때만 파란 구간의 양끝을 드래그하세요. 오른쪽 시작·끝에 시간을 입력하고 수정 적용을 눌러도 됩니다. 이 값은 실제 저장 구간을 바꿉니다. 시작 부분 재생·끝 부분 재생으로 확인하세요.

클립 시작·끝 일괄 조정에서 시작 오프셋·끝 오프셋을 입력하고 모든 클립에 일괄 적용을 누르세요. 예: 시작 −10초, 끝 +10초는 곡 앞뒤를 10초씩 더 담습니다.

현재 영상의 자동 인식 클립에 적용됩니다. 매번 자동 인식 원본을 기준으로 계산하며, 직접 추가한 클립은 그대로 둡니다. 개별로 시간을 수정한 클립이 있으면 유지할지 선택할 수 있습니다.

직접 추가·합치기·되돌리기

클립 직접 추가는 현재 구간을 추가합니다. Shift·Ctrl로 여러 클립을 선택하고 선택한 클립 합치기를 누르면 합칩니다. 목록에서 제거는 목록에서 제거하고, 되돌리기는 직전 편집을 되돌립니다.

5. 저장 대상 확정 및 파일 저장

클립 탭에서 폴더와 파일명을 확인한 뒤 저장하세요.

폴더 선택으로 저장 위치를 고르세요. 날짜 폴더 옵션을 켜면 내보낼 때 하위 폴더를 만듭니다.

저장할 파일명에서 결과 이름을 확인하세요. 이름이 겹치면 번호가 붙습니다.

저장 설정에서 자르는 방식과 화질을 정하세요. 적용으로 적용하세요.

파일 …개 저장 시작을 누르세요. 완료 후 선택한 폴더 열기로 결과를 여세요.

저장 결과 확인

하단의 성공·실패 수를 확인하세요. 일부 클립이 실패하면 실패한 클립에 체크가 남습니다. 클립 선택으로 돌아가기에서 대상을 확인한 뒤 다시 저장하세요. 원인은 Settings → 진단에서 확인할 수 있습니다.

저장 방식과 화질

시작·끝을 정확히 맞추려면 정확한 구간 자르기를 쓰세요.

프리셋을 고른 뒤 프리셋 적용을 누르세요. 창 아래 적용을 눌러 확정하세요.

정확한 구간 자르기는 지정한 경계에 맞춰 변환합니다. 원본 빠른 복사는 빠르지만 경계가 조금 달라질 수 있습니다.

클립당 목표 크기는 클립별 목표 크기입니다. 0이면 화질 기준으로 저장합니다. 실제 크기는 달라질 수 있습니다.

소리 포함으로 소리를 포함하세요. 음량 조절의 0은 원래 음량입니다.

CPU로 저장할 때는 처리 속도를 고르세요. GPU로 영상 압축을 켜면 사용 가능한 GPU 인코더로 저장합니다. GPU 압축을 선택하면 처리 속도 선택이 비활성화됩니다.

화질과 크기를 고르는 기준

원본 빠른 복사는 원본 화질로 빠르게 저장합니다. 화질·크기·음량을 바꾸려면 정확한 구간 자르기를 선택하세요.

처음에는 균형 있게 · 일반적인 공유용을 쓰세요. 더 선명하게 보려면 선명하게 · 용량 큼, 파일을 줄이려면 작게 · 화질보다 용량 우선을 고르세요. 목표 크기를 지정하면 그 크기를 기준으로 저장하며 화질 선택은 비활성화됩니다.

천천히 · 같은 화질에서 용량 절약은 압축에 더 많은 시간을 씁니다. 줄어드는 용량은 영상에 따라 다릅니다. 목표 크기를 지정했다면 느리게 저장해도 파일이 더 작아지는 설정은 아닙니다. 설정을 고른 뒤 창 아래 적용을 누르세요.

긴 영상에 챕터 넣기

클립 확인에서 사용할 클립을 고르고 저장 설정 화면의 챕터 탭을 여세요.

챕터 형식에서 제목을 정하세요. 예: {title}은 곡명입니다. 곡 사이 쉬는 구간도 나누려면 곡과 곡 사이에도 챕터 넣기를 켜고 공백 챕터 이름을 입력하세요.

YouTube 설명란에서 전체 영상 기준의 시간과 제목을 확인하세요. 위쪽에 길이·개수 안내가 나오면 클립 구간을 조정하세요.

설명란 내용 복사를 누르고 YouTube 영상 설명란에 붙여넣으세요.

챕터를 넣은 영상 저장을 누르고 새 파일 위치를 정하세요. 영상 전체를 원본 화질로 복사하면서 챕터를 넣습니다.

저장 방법 · 둘 중 필요한 것 사용

설명란 복사와 영상 저장은 각각 사용할 수 있습니다. 클립별 파일은 클립 탭에서 저장하세요.

YouTube 구간 가져오기

영상 열기 화면에서 YouTube 링크를 붙여넣고 영상 정보 확인 →를 누르세요.

슬라이더 양끝을 끌거나 시작·끝에 시간을 입력하세요. 시간축에서 보고 싶은 위치를 누르고 1초 기다리면 미리보기가 나옵니다. 현재 위치를 시작으로·현재 위치를 끝으로로 경계를 정할 수도 있습니다.

동시 다운로드 수는 기본 4개입니다. 처음에는 녹색 범위인 1–4개를 사용하세요. 요청 제한 오류가 나면 수를 줄이고 잠시 후 다시 시도하세요.

선택 구간 다운로드를 누르세요.

오른쪽에서 현재 단계·진행률·예상 남은 시간을 확인하세요. 완료되면 영상 선택 화면으로 돌아옵니다. 받은 영상에서 인식할 구간과 정확한 클립 경계를 조정하세요.

일반 영상·지난 라이브·진행 중인 라이브

일반 영상과 처리가 끝난 지난 라이브는 영상 시작부터의 시간을 씁니다. 방송 종료 직후 처리 중이면 잠시 후 정보를 다시 확인하세요.

진행 중인 라이브는 조회한 최신 지점부터 거꾸로 표시합니다. -30:00부터 -00:00까지는 마지막 30분입니다. 접근 가능한 과거 구간은 시간축 왼쪽 끝에서 확인하세요. 더 최신 구간을 받으려면 정보 새로고침을 누르고 구간을 다시 정하세요.

미리보기는 낮은 해상도로 표시됩니다. 다운로드할 영상의 화질은 미리보기 화질과 별개입니다.

다운로드 상태 확인

선택 구간 다운로드를 누른 뒤 오른쪽 진행 상태를 확인하세요.

구간 확인 → 원본 다운로드 → 병합·검증 → 완료 순서로 진행됩니다. 다운로드 단계에서는 받은 조각 수와 현재 단계의 예상 남은 시간이 표시됩니다.

진행이 느리면 아래 기록에서 마지막 문구를 확인하세요. 조각 병렬 다운로드를 지원하지 않는 영상은 일반 다운로드 방식으로 받습니다.

중지하려면 창 아래 취소를 누르세요. 오류로 멈추면 문구를 확인하고 정보 새로고침으로 영상을 다시 조회한 뒤 구간을 정하세요.

작업 저장하고 이어하기

다음에 이어할 편집 내용은 작업 저장으로 저장하세요.

작업 저장으로 JSON 파일을 저장하세요. 영상별 클립, 편집 내용, 재생 음량을 보관합니다.

작업 열기에서 저장한 JSON을 고르세요. 원본 영상은 같은 경로에 보관하세요.

영상 파일이 필요하다면

완성 영상은 파일 저장에서 만드세요. 작업 JSON은 원본 영상을 포함하지 않습니다.

언어와 앱 설정

상단 Settings 버튼으로 여세요.

일반 탭의 Language에서 한국어·English를 고르세요. 앱을 다시 열면 적용됩니다.

클립 선택·재생 위치를 따라 확대 시간축 이동을 켜면 클립이나 재생 위치가 바뀔 때 확대 시간축이 따라갑니다.

데이터 폴더 변경…에서 새 위치를 고르세요. 기존 자켓을 옮기거나 복사할 수 있습니다. 새 폴더 준비가 끝나면 앱이 다시 시작됩니다.

다른 설정 열기

자켓 업데이트는 자켓 데이터, 곡·글자 판독은 인식, 오류 기록은 진단, 버전 확인은 정보 탭에서 여세요.

자켓 데이터 받기·업데이트

Settings → 자켓 데이터를 여세요.

내려받을 서버를 고르세요. 별도로 안내받은 주소가 있다면 직접 입력을 선택하고 곡 목록·자켓 이미지 주소를 입력하세요.

자켓 데이터 업데이트를 누르고 완료될 때까지 기다리세요. 곡 수·보유 자켓 수·용량을 확인할 수 있습니다.

다음 데이터 사용에서 받은 데이터를 고르세요. 여러 서버의 데이터를 함께 쓰려면 모든 데이터를 선택하세요.

인식이 잘 안 될 때

Settings → 인식을 여세요. 먼저 인식 영역과 현재 장면이 맞는지 확인하세요.

자켓 위치 보정 간격 (초)을 줄이면 자켓 위치를 더 자주 확인합니다.

곡 확인 간격 (초)을 줄이면 더 자주 확인합니다. 비슷한 자켓을 혼동하면 자켓 차이 허용값을 낮추거나 두 후보의 최소 점수 차이를 높여 보세요.

이름·달성률을 읽는 시간을 늘리려면 곡 끝 글자 확인 범위 (초)를 늘리세요. 글자 영역이 실제 글자를 감싸는지도 확인하세요.

처음에는 자동값을 사용하세요. 작업 수를 높이면 CPU·메모리 사용이 늘 수 있습니다. 변경한 값은 다음 분석부터 적용됩니다.

바꾼 뒤 다시 확인

닫기로 돌아가 인식 영역 화면의 현재 화면 인식 확인을 누르세요. 같은 촬영 구도에 쓸 값은 프로필 저장으로 보관하세요.

오류 확인·문제 신고

Settings → 진단을 여세요.

오류가 난 작업과 마지막 기록을 확인하세요. 다운로드 오류라면 사용한 링크와 선택 구간도 함께 적어 두세요.

재생·다운로드 도구 오류라면 FFmpeg·다운로드 도구 확인을 누르고 위 기록을 확인하세요.

문제 신고를 누르면 브라우저에서 신고 양식이 열립니다. 재현 순서와 오류 기록을 넣고 내용을 확인한 뒤 제출하세요.

버전 확인·라이선스

Settings → 정보를 여세요.

새 버전 확인을 누르세요. 새 버전이 있으면 다운로드 페이지를 열 수 있습니다.

오픈소스 라이선스 보기에서 포함된 라이브러리와 도구의 고지문을 확인하세요.

자켓 데이터가 없다고 나오는 경우 / 신곡이 나왔을 경우

Settings → 자켓 데이터 → 자켓 데이터 업데이트를 누르세요. 다운로드가 끝나면 다시 곡을 찾으세요.

검색어를 지우고 곡 미확인 구간 표시를 켜세요. 현재 영상이 맞는지 확인하세요.

저장 후 시작·끝이 달라요

저장 설정에서 정확한 구간 자르기를 고르세요.

이름이 틀리게 나와요

1P 이름 영역이 글자를 정확히 감싸는지 확인하세요. 이름을 고친 뒤 수정 적용을 누를 수도 있습니다.

0. How does it work?

Find songs in a video, then save the sections you need as clips. The source video stays unchanged.

  1. Open video
  2. Set time range
  3. Mark song/text regions → Find songs
  4. Review clips and confirm what to save
  5. Save video files

On your first launch, start with Welcome below. If setup is complete, go to Open a video.

Which videos does this work with?

Songs are recognized by comparing the jacket on screen with the official art, so the jacket has to sit inside the region square and uncropped.

Welcome · First launch

Choose where to keep the files used for song recognition.

Use Choose folder to choose a data folder. The first launch downloads about 100 MB of song jackets.

Click Get started →. The download may take about 10 minutes. Wait for it to finish.

To use another server

Open Advanced and choose Download from. Later launches reuse the downloaded files. Get new songs from Settings → Jacket data → Update jacket data.

1. Open a video

Open a video using either files or a folder.

Open files or a folder · Choose one

Click Add files. Choose a video file to open its preview.

Click Add folder to add several videos. You can also drag video files into the window.

Check the opened video

Choose a video in Current video. The clip list switches to that video.

Once the video opens, click Select range →.

To import from YouTube

Paste the address into YouTube link on the right, then click Check video details →. The download screen opens after the video details load.

Download a YouTube range →

2. Set the time range

Use any one of methods A–C to set the start and end.

Set the range · Choose one method

Enter Start and End times. For example, 00:01:30.000 means 1 minute and 30 seconds.

At the first scene, click Set start here. At the last scene, click Set end here.

Drag either edge of the blue selection. Use Play selection to check the range.

Continue

When the range is right, click Recognition regions →.

To scan the whole video

Click Full range.

3. Mark song and text regions

Reuse a saved profile for the same camera layout.

Choose or create a profile

Choose a profile in Select profile. Use the import icon on its right to open a shared JSON or ZIP file.

Create a new profile

Choose Jacket (the song artwork) in Choose region.

Drag around the whole jacket. Define separate regions around the 1P name and 1P achievement text. Compare the example and Current region on the right to check the crop.

Save or share a profile

Jacket, 1P name, and 1P achievement are required. Add 2P regions when needed. Use Save profile to reuse the layout, or Export profile to share a JSON or ZIP file.

Test recognition and find songs

Click Test current frame. Check the detected song title and player name.

Click Find songs in range →. Finding songs in a long video can take a while. Check progress at the bottom.

4. Review clips

Select a clip to edit it. Check its box to mark it for saving.

Select clips to save

Select a row to edit that clip. Use its checkbox to mark it for saving.

Search a player name to narrow the list. Check visible clips checks the visible items. Hidden clips keep their checkmarks, so check the export count at the bottom before continuing.

Confirm your clips with Export … checked clips → or Export … visible clips →. Save the files on the next screen.

Edit clips · Optional

To change a filename or chapter title, edit the song title, player names, or achievement and click Apply edits. You can mark a checked clip with Mark as reviewed.

If needed, drag either edge of the blue selection. You can also enter Start and End times on the right and click Apply edits. These values change the saved video range. Check it with Preview start and Preview end.

In Adjust all clip boundaries, enter Start offset and End offset, then click Apply to all clips. For example, −10 seconds at the start and +10 seconds at the end includes 10 extra seconds on each side.

This affects detected clips in the current video. Each application uses the original detection times; it does not keep adding time. Manually added clips stay unchanged. If you edited a clip’s boundaries individually, you can choose to keep them.

Add, merge, or undo

Add clip manually adds the current range. Select clips with Shift or Ctrl, then click Merge selected clips to combine them. Remove from list removes clips; Undo restores the last edit.

5. Confirm and save video files

In the Clips tab, check the folder and filenames, then save.

Choose an output folder with Choose folder. The date-folder option creates a subfolder when export starts.

Check the names under Output filenames. Duplicate filenames get a number suffix.

Open Export settings to choose trimming and quality options. Click Apply to use them.

Click Export … files. When it finishes, use Open selected folder to view the results.

Check the result

Check the success and failure counts at the bottom. If some clips fail, those clips are checked for retry. Use Back to clip selection to review them before exporting again. Read the error in Settings → Diagnostics.

Trim method and quality

Use Frame-accurate trim for exact start and end times.

Choose a preset and click Apply preset. Confirm with Apply at the bottom of the window.

Frame-accurate trim re-encodes at your chosen boundaries. Fast source copy is faster, but the boundaries may shift slightly.

Target size per clip sets a size target for each clip. Zero uses the quality setting. Actual sizes can vary.

Enable Include audio to keep sound. A Volume adjustment of 0 keeps the original level.

For CPU encoding, choose Encoding speed. Enable Encode video on GPU to use an available GPU encoder. The encoding-speed choice is disabled while GPU encoding is selected.

Choosing quality and size

Fast source copy saves quickly at the source quality. Choose Frame-accurate trim to change quality, size, or volume.

Start with Balanced · For general sharing. Choose High quality · Larger files for more detail or Small files · Lower quality for smaller files. Setting a target size uses that size instead of the quality choice.

Slow · Smaller files at the same quality spends more time compressing. The size saving depends on the video. With a target size set, slower encoding does not select a smaller file size. Finish by clicking Apply at the bottom.

Add chapters to a recording

Choose clips in Review clips, then open the Chapters tab on the export screen.

Set the title in Chapter format. For example, {title} inserts the song title. To mark breaks between songs, enable Add a chapter between songs too and enter a Gap chapter name.

Check the times and titles in YouTube description. Times are relative to the whole recording. If a duration or chapter-count notice appears above, adjust the clip ranges.

Click Copy the description, then paste the text into your YouTube video description.

Click Save a video with chapters and choose a new file location. This copies the full recording at source quality and adds chapters.

Output choices · Use either as needed

Copying the description and saving a chaptered video are separate choices. Use the Clips tab for individual clip files.

Download a YouTube range

On the video selection screen, paste a YouTube link and click Check video details →.

Drag either slider handle or enter Start and End times. Click a position on the timeline and wait one second for a preview. You can also set boundaries with Set start here and Set end here.

Concurrent downloads defaults to 4. Start within the green range of 1–4. If requests are limited, lower the count and wait before trying again.

Click Download selection.

Check the current step, progress, and estimated time remaining on the right. When finished, the app returns to Select video. Use the downloaded video to choose the scan range and fine-tune clip boundaries.

Videos, past broadcasts, and live streams

Regular videos and processed past broadcasts use elapsed time from the start. If a broadcast has just ended and is still processing, wait and check its details again.

Live streams count backward from the latest point found at lookup. -30:00 to -00:00 selects the last 30 minutes. The left end of the timeline shows the oldest accessible point. For newer footage, click Refresh info and select the range again.

Previews use a low resolution. Their quality does not determine the downloaded video quality.

Check download progress

After clicking Download selection, watch the progress on the right.

The steps are range checks, original download, merging and validation, and completion. During download, the app shows the fragment count and estimated time left for that step.

If progress is slow, check the last message in the log. Videos without parallel fragment support use the standard download method.

Click Cancel at the bottom to stop. If an error stops the download, read the message, use Refresh info, and select the range again.

Save and resume a session

Use Save session to keep your edits for later.

Save a JSON file with Save session. It keeps each video’s clips, edits, and playback volume.

Choose the saved JSON with Open session. Keep the source videos at their original paths.

To create video files

Create finished videos in Export clips. The session JSON does not contain the source videos.

Language and app settings

Open Settings from the top bar.

In General, choose 한국어 or English under 언어. Reopen the app to apply it.

Enable Follow selected clip and playhead in the zoomed timeline to keep the selected clip or playhead in the zoomed timeline.

Use Change data folder… to choose a new location. You can move or copy existing jackets. The app restarts when the new folder is ready.

Open other settings

Use Jacket data for artwork updates, Recognition for song and text recognition, Diagnostics for errors, and About for version checks.

Download or update jacket data

Settings → Jacket data opens these controls.

Choose Download from. If you have been given other addresses, select Enter an address and enter the song-list and artwork-image addresses.

Click Update jacket data and wait for it to finish. Check the song count, jacket count, and storage size.

Choose downloaded data in Recognize with. Select All data to use data from several servers together.

Improve recognition

Open Settings → Recognition. First check that the regions and current frame are correct.

Lower Jacket alignment interval (s) to check the jacket position more often.

Lower Song scan interval (s) to scan more often. If similar jackets get confused, try lowering Jacket difference threshold or raising Minimum score gap between candidates.

Increase Text scan window at song end (s) to read text over a longer interval near the song’s end. Check that the text regions frame the actual text.

Start with the automatic values. More workers can use more CPU and memory. Changes take effect on the next analysis.

Check after changing settings

Click Close, return to Recognition regions, and use Test current frame. Keep settings for this camera layout with Save profile.

Check errors and report a problem

Open Settings → Diagnostics.

Find the failed operation and its last log message. For a download error, also note the link and selected range.

For media or download-tool errors, click Check FFmpeg and download tools and read the results above.

Report a problem opens a report form in your browser. Add the steps to reproduce and the error log, then review and submit it.

Check the version and licenses

Open Settings → About.

Click Check for a new version. If a new version is available, you can open its download page.

Open View open source licenses to read notices for the included libraries and tools.

Troubleshooting and shortcuts

Jacket data is missing / A new song was released

Open Settings → Jacket data → Update jacket data. When the download finishes, find songs again.

No clips are visible

Clear the search and enable Show unidentified song sections. Check Current video.

Exported boundaries shifted

Choose Frame-accurate trim in Export settings.

Player names are wrong

Check that the 1P name region frames the text. You can also edit the name and click Apply edits.
