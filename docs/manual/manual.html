0. 어떻게 진행되나요?

영상에서 곡을 찾고, 필요한 구간을 클립으로 저장합니다. 원본 영상은 그대로 유지됩니다.

  1. 영상 열기
  2. 시간 범위 지정
  3. 곡·글자 위치 지정 → 곡 찾기
  4. 클립 확인·저장 대상 확정
  5. 영상 파일 저장

처음 실행한다면 다음 ‘환영합니다’부터 시작하세요. 이미 설정했다면 ‘영상 열기’로 이동하세요.

어떤 영상에서 곡을 찾을 수 있나요?

곡 인식은 화면의 자켓을 공식 자켓과 비교하는 방식입니다. 인식 영역 안에 자켓이 정사각형 그대로, 잘리지 않고 들어와야 인식됩니다.

환영합니다 · 처음 한 번

데이터 폴더를 정하면 곡 인식에 필요한 파일을 받습니다.

폴더 선택으로 데이터 폴더를 지정하세요. 최초 1회 곡 자켓 약 100 MB를 다운로드합니다.

시작하기 →를 누르세요. 다운로드에 약 10분이 걸릴 수 있습니다. 완료될 때까지 기다리세요.

다음 실행부터

같은 데이터 폴더의 파일을 다시 사용합니다. 신곡은 Settings → 자켓 데이터 업데이트로 받으세요.

시간 범위 지정 · 세 방법 중 하나

3. 곡과 글자 위치 지정하기

같은 촬영 구도라면 저장한 프로필을 사용하세요.

프로필 고르기 또는 새 프로필 만들기

프로필 선택에서 프로필을 고르세요. 받은 JSON·ZIP 파일은 오른쪽 가져오기 아이콘으로 여세요.

새 프로필 만들기

영역 선택에서 자켓(곡 이미지)을 고르세요.

곡 이미지를 감싸도록 드래그하세요. 1P 이름과 1P 달성률도 각각 영역을 지정하세요.

팁 · 프로필을 새로 만들 때

필수 영역은 자켓·1P 이름·1P 달성률입니다. 2P 영역은 필요할 때 추가하세요. 프로필 저장으로 저장하면 다음 영상에서도 사용할 수 있습니다.

인식 확인과 곡 찾기

현재 화면 인식 확인을 누르세요. 인식한 곡명과 이름을 확인하세요.

이 구간에서 곡 찾기 →를 누르세요. 긴 영상은 곡 찾기에 시간이 오래 걸릴 수 있습니다. 하단 진행 상태를 확인하세요.

4. 클립 확인하기

클립을 선택하면 편집할 수 있습니다. 체크박스는 저장할 클립을 표시합니다.

저장할 클립 선택하기

목록에서 클립을 선택하면 편집할 수 있습니다. 저장할 클립은 체크박스로 표시하세요.

이름을 검색해 목록을 좁히세요. 보이는 클립 체크는 현재 보이는 항목에 체크합니다.

체크한 클립 …개 저장 설정 → 또는 보이는 클립 …개 저장 설정 →로 저장 대상을 확정하세요. 파일은 다음 화면에서 저장합니다.

클립 수정하기 · 선택 사항

곡명·이름·달성률은 파일명을 만들 때 쓰는 정보입니다. 영상에 글자로 입혀지지 않으므로, 파일명이 괜찮다면 수정하지 않아도 됩니다. 바꾼 뒤 수정 적용을 누르세요.

필요할 때만 파란 구간의 양끝을 드래그하세요. 오른쪽 시작·끝에 시간을 입력하고 수정 적용을 눌러도 됩니다. 이 값은 실제 저장 구간을 바꿉니다. 시작 부분 재생·끝 부분 재생으로 확인하세요.

클립 시작·끝 일괄 조정에서 시작 오프셋·끝 오프셋을 입력하고 모든 클립에 일괄 적용을 누르세요. 예: 시작 −10초, 끝 +10초는 곡 앞뒤를 10초씩 더 담습니다.

현재 영상의 자동 인식 클립에 적용됩니다. 매번 자동 인식 원본을 기준으로 계산하며, 직접 추가한 클립은 그대로 둡니다. 개별로 시간을 수정한 클립이 있으면 유지할지 선택할 수 있습니다.

직접 추가·합치기·되돌리기

클립 직접 추가는 현재 구간을 추가합니다. Shift·Ctrl로 여러 클립을 선택하고 선택한 클립 합치기를 누르면 합칩니다. 목록에서 제거는 목록에서 제거하고, 되돌리기는 직전 편집을 되돌립니다.

5. 저장 대상 확정 및 파일 저장

폴더와 파일명을 확인한 뒤 내보내세요.

폴더 선택으로 저장 위치를 고르세요. 날짜 폴더 옵션을 켜면 내보낼 때 하위 폴더를 만듭니다.

저장할 파일명에서 결과 이름을 확인하세요. 이름이 겹치면 번호가 붙습니다.

저장 설정에서 자르는 방식과 화질을 정하세요. 적용으로 적용하세요.

파일 …개 저장 시작을 누르세요. 완료 후 선택한 폴더 열기로 결과를 여세요.

저장이 일부 실패했다면

하단 성공·실패 수와 진단 로그를 확인하세요. 실패한 클립을 저장 대상으로 다시 지정한 뒤 저장하세요.

저장 방식과 화질

시작·끝을 정확히 맞추려면 정확한 구간 자르기를 쓰세요.

프리셋을 고른 뒤 프리셋 적용을 누르세요. 창 아래 적용을 눌러 확정하세요.

정확한 구간 자르기는 지정한 경계에 맞춰 변환합니다. 원본 빠른 복사는 빠르지만 경계가 조금 달라질 수 있습니다.

클립당 목표 크기는 클립별 목표 크기입니다. 0이면 화질 기준으로 저장합니다. 실제 크기는 달라질 수 있습니다.

소리 포함으로 소리를 포함하세요. 음량 조절의 0은 원래 음량입니다.

화질·속도·저장 방식의 차이

자르는 방식이 원본 빠른 복사이면 화질을 바꾸지 않고 원본을 그대로 복사합니다. 화질·용량을 조절하려면 정확한 구간 자르기를 선택하세요.

처음에는 균형 있게 · 일반적인 공유용을 쓰세요. 더 선명한 영상을 원하면 선명하게 · 용량 큼, 파일을 작게 만들려면 작게 · 화질보다 용량 우선을 선택하세요. 작은 파일을 택하면 세부 표현이 뭉개질 수 있습니다.

처리 속도는 영상의 재생 속도가 아니라 저장을 끝내는 데 걸리는 시간입니다. 빠르게 처리는 빨리 저장합니다. 천천히 · 같은 화질에서 용량 절약은 더 오래 계산해 비슷한 화질을 더 적은 용량에 담습니다. 여유가 있을 때 선택하세요.

YouTube 구간 가져오기

영상 열기 화면에서 YouTube 링크를 붙여넣고 영상 정보 확인 →를 누르세요.

시작·끝에 필요한 구간을 입력하세요. 정확한 경계는 다운로드 후 다음 단계에서 조정할 수 있습니다.

동시 다운로드 수는 기본 4개입니다. 녹색 1–4개를 권장합니다. 붉은색 5–16개는 요청 제한 가능성이 커집니다.

권장 범위에서도 요청이 제한될 수 있습니다. 오류가 나면 수를 줄이고 잠시 후 다시 시도하세요.

선택 구간 다운로드를 누르세요.

진행률과 현재 단계의 예상 남은 시간을 확인하세요. 완료되면 영상 선택 화면으로 돌아옵니다.

조각 병렬 다운로드를 지원하지 않으면 화면에 안내되며 일반 방식으로 받습니다.

작업 저장하고 이어하기

다음에 이어할 편집 내용은 작업 저장으로 저장하세요.

작업 저장으로 JSON 파일을 저장하세요. 클립과 편집 정보를 보관합니다.

작업 열기에서 저장한 JSON을 고르세요. 원본 영상은 같은 경로에 보관하세요.

완성 영상은 파일 저장에서 만드세요. 작업 JSON은 원본 영상을 포함하지 않습니다.

적용으로 저장하세요. 인식 영역 화면에서 현재 화면 인식 확인으로 다시 확인하세요.

0. How does it work?

Find songs in a video, then save the sections you need as clips. The source video stays unchanged.

  1. Open video
  2. Set time range
  3. Mark song/text regions → Find songs
  4. Review clips and confirm what to save
  5. Save video files

On your first launch, start with Welcome below. If setup is complete, go to Open a video.

Which videos does this work with?

Songs are recognized by comparing the jacket on screen with the official art, so the jacket has to sit inside the region square and uncropped.

Welcome · First launch

Choose where to keep the files used for song recognition.

Use Choose folder to choose a data folder. The first launch downloads about 100 MB of song jackets.

Click Get started →. The download may take about 10 minutes. Wait for it to finish.

On later launches

Files in the same data folder are reused. Get new songs with Settings → Update jacket data.

1. Open a video

Open a video using either files or a folder.

Open files or a folder · Choose one

Click Add files. Choose a video file to open its preview.

Click Add folder to add several videos. You can also drag video files into the window.

Check the opened video

Choose a video in Current video. The clip list switches to that video.

Once the video opens, click Select range →.

For a YouTube video

Use Download a YouTube range below to get only the part you need.

Download a YouTube range →

2. Set the time range

Use any one of methods A–C to set the start and end.

Set the range · Choose one method

Enter Start and End times. For example, 00:01:30.000 means 1 minute and 30 seconds.

At the first scene, click Set start here. At the last scene, click Set end here.

Drag either edge of the blue selection. Use Play selection to check the range.

Continue

When the range is right, click Recognition regions →.

To scan the whole video

Click Full range.

3. Mark song and text regions

Reuse a saved profile for the same camera layout.

Choose or create a profile

Choose a profile in Select profile. Use the import icon on its right to open a shared JSON or ZIP file.

Create a new profile

Choose Jacket (the song artwork) in Choose region.

Drag around the song artwork. Define separate regions for 1P name and 1P achievement too.

Tip · Creating a profile

4. Review clips

Select a clip to edit it. Check its box to mark it for saving.

Select clips to save

Select a row to edit that clip. Use its checkbox to mark it for saving.

Search a player name to narrow the list. Check visible clips checks the items currently shown.

Confirm your clips with Export … checked clips → or Export … visible clips →. Save the files on the next screen.

Edit clips · Optional

Song titles, names, and achievement values are used to build filenames. They are not drawn onto the video. Skip these edits if the filename is fine. Click Apply edits after making changes.

If needed, drag either edge of the blue selection. You can also enter Start and End times on the right and click Apply edits. These values change the saved video range. Check it with Preview start and Preview end.

In Adjust all clip boundaries, enter Start offset and End offset, then click Apply to all clips. For example, −10 seconds at the start and +10 seconds at the end includes 10 extra seconds on each side.

This affects detected clips in the current video. Each application uses the original detection times; it does not keep adding time. Manually added clips stay unchanged. If you edited a clip’s boundaries individually, you can choose to keep them.

Add, merge, or undo

Add clip manually adds the current range. Select clips with Shift or Ctrl, then click Merge selected clips to combine them. Remove from list removes clips; Undo restores the last edit.

If some exports fail

Trim method and quality

Use Frame-accurate trim for exact start and end times.

Choose a preset and click Apply preset. Confirm with Apply at the bottom of the window.

Frame-accurate trim re-encodes at your chosen boundaries. Fast source copy is faster, but the boundaries may shift slightly.

Target size per clip sets a size target for each clip. Zero uses the quality setting. Actual sizes can vary.

Enable Include audio to keep sound. A Volume adjustment of 0 keeps the original level.

Quality, speed, and trim methods

Fast source copy copies the original video without changing its quality. Choose Frame-accurate trim to adjust quality and file size.

Start with Balanced · For general sharing. Choose High quality · Larger files for more detail, or Small files · Lower quality for smaller files. Smaller files may lose fine detail.

Processing speed controls how long saving takes, not how fast the video plays. Fast finishes sooner. Slow · Smaller files at the same quality spends more time fitting similar quality into a smaller file. Use it when you can wait.

Download a YouTube range

On the video selection screen, paste a YouTube link and click Check video details →.

Enter the range in Start and End. You can adjust the exact boundaries in the next step after downloading.

Concurrent downloads defaults to 4. Green (1–4) is recommended. Red (5–16) means greater risk of request limits.

Requests may be limited even in the recommended range. If errors occur, lower the count and wait before trying again.

Click Download selection.

Check the progress and estimated time remaining for the current step. When the download finishes, you return to the video selection screen.

If parallel fragment downloads are unavailable, the screen shows a notice and uses the standard method.

Open Jacket and text recognition… to adjust song and text recognition.

Use automatic values. Decoder threads read frames; jacket workers compare artwork. Higher values can use more CPU and memory. Changes apply to the next analysis.

Read the Diagnostic log for details. For tool errors, click Check FFmpeg and download tools.

Improve recognition

Check the regions and current frame first.

Lower Jacket alignment interval (s) to check the position more often.

Lower Song scan interval (s) to check more often. If similar jackets get mixed up, try a lower Jacket difference threshold.

Click Apply. Return to Recognition regions and use Test current frame again.

Troubleshooting and shortcuts

Jacket data is missing / A new song was released

Open Settings → Update jacket data. When the download finishes, find songs again.

No clips are visible

Clear the search and enable Show unidentified song sections. Check Current video.

Exported boundaries shifted

Choose Frame-accurate trim in Export settings.

Player names are wrong

Check that the 1P name region frames the text. You can also edit the name and click Apply edits.
