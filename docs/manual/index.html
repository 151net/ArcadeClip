ArcadeClip

길게 녹화한 maimai 영상을 곡별 MP4 파일로 나눕니다.

Split a long maimai recording into one MP4 per song.

소개

About

아케이드 녹화 영상 하나에는 곡이 여러 개 들어 있습니다. 곡마다 시작과 끝을 찾아 직접 자르려면 시간이 오래 걸리고, 파일 이름도 하나씩 붙여야 합니다.

One arcade recording holds several songs. Cutting each one by hand takes a long time, and every file still needs a name.

ArcadeClip은 영상 속 자켓으로 곡을 인식하고, 이름과 달성률을 읽어 파일 이름을 만듭니다. 결과를 확인한 뒤 저장할 클립만 고르면 됩니다.

ArcadeClip finds the songs by the jacket shown in the video, and reads the name and achievement to build the file names. You check the result and pick the clips to save.

주요 기능

Features

  • 곡 찾기

    Find songs

    화면의 자켓을 공식 자켓과 비교해 곡이 바뀌는 지점을 찾습니다.

    Compares the jacket on screen with the official song art to find where each song starts and ends.

  • 이름과 달성률 읽기

    Read names and achievements

    화면의 글자를 읽어 곡명·이름·달성률로 파일 이름을 만듭니다.

    Reads the text on screen and builds file names from the song title, player name, and achievement.

  • YouTube 구간 가져오기

    Download a YouTube range

    링크를 붙여넣고 필요한 구간만 받습니다. 영상 전체를 받지 않아도 됩니다.

    Paste a link and download only the range you need, not the whole video.

  • 저장 방식 선택

    Choose how to save

    원본 빠른 복사로 빠르게 저장하거나, 정확한 구간 자르기로 시작·끝을 맞춥니다.

    Pick Fast source copy for speed, or Frame-accurate trim to match the start and end you set.

  • 프로필

    Profiles

    인식 영역을 프로필로 저장해 두면 같은 촬영 구도의 다음 영상에서 그대로 씁니다. 오락실별로 프로필을 만들어 관리해 보세요.

    Save the regions as a profile and use it again on the next video shot the same way. Keep one profile per game center.

  • 한국어와 English

    Korean and English

    앱 표시 언어와 사용 설명서를 두 언어로 제공합니다.

    The app and the user guide are available in both languages.

한계

Limits

곡 인식은 화면의 자켓을 공식 자켓과 비교하는 방식입니다. 인식 영역 안에 자켓이 정사각형 그대로, 잘리지 않고 들어와야 인식됩니다.

Songs are recognized by comparing the jacket on screen with the official art, so the jacket has to sit inside the region square and uncropped.
